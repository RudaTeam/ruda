# ADR-0003: Лицензия Apache-2.0 и политика зависимостей

- **Статус:** Принято
- **Дата:** 2026-10-01 (с 2026-09-30 решение было отложено)
- **Связанные ADR:** 0002, 0014, 0015

## Контекст

Репозиторий публичный. Цель владельца — **разрешить любые форки**, включая закрытые и
коммерческие, но **обязательно с упоминанием автора**.

От лицензии проекта зависят и зависимости: если в бинарник попадёт крейт под копилефтом,
его условия распространятся на всю сборку.

## Рассмотренные варианты

1. **MIT** — разрешает всё. Атрибуция — только строка копирайта в файле LICENSE; её легко «закопать».
2. **Apache-2.0** — разрешает всё. Форк обязан распространять файл `NOTICE` с атрибуцией и помечать изменённые файлы. Есть явная патентная лицензия.
3. **MIT OR Apache-2.0** — стандарт экосистемы Rust. Но форкер сам выбирает MIT, и обязанность нести `NOTICE` исчезает.
4. **Копилефт (GPL, AGPL), source-available (BSL, FSL), проприетарная** — ограничивают форки, а это против цели.

## Решение

**Ruda распространяется под Apache-2.0** — только под ней, без двойного лицензирования.

- Правообладатель: **RudaTeam / F4 Studio**.
- В корне репозитория лежат `LICENSE` (полный текст Apache-2.0) и `NOTICE` (атрибуция). По разделу 4(d) лицензии любая производная работа обязана сохранять атрибуцию из `NOTICE` в своём дистрибутиве: в файле `NOTICE`, в документации или там, где программа показывает сторонние уведомления.
- В `Cargo.toml` указаны `license = "Apache-2.0"` и `publish = false` (публиковать крейты пока незачем).
- **Вклад контрибьюторов** по разделу 5 лицензии автоматически идёт под Apache-2.0. Авторские права на свой вклад контрибьюторы сохраняют. Отдельный CLA не нужен.
- **Ассеты** пока своих нет: всё в репозитории подпадает под Apache-2.0. Если для своих ассетов понадобится другая лицензия (например, CC-BY-4.0), решим отдельным ADR.
- **SDK для моддеров** — тоже Apache-2.0. Моды могут выходить под любой лицензией, включая закрытую (ADR-0014).

**Зависимости** проверяет `cargo-deny` в CI. Допускаются только разрешительные лицензии,
чтобы сборки Ruda оставались распространяемыми под Apache-2.0:

| Категория | Лицензии |
|---|---|
| Разрешены | MIT, Apache-2.0 (в т.ч. WITH LLVM-exception), BSD-2-Clause, BSD-3-Clause, ISC, Zlib, BSL-1.0, Unicode-3.0, CC0-1.0 |
| По согласованию | MPL-2.0 (копилефт на уровне файла: если меняем такие файлы, их исходники нужно публиковать) |
| Запрещены | GPL, LGPL, AGPL, SSPL, любые некоммерческие (NC), крейты без лицензии |

**Атрибуция зависимостей.** `cargo-about` генерирует список лицензий зависимостей в файл
`THIRD_PARTY_LICENSES`, и он поставляется с каждой сборкой. В игре есть экран «Лицензии»:
на нём `NOTICE` самой Ruda и лицензии зависимостей.

**Сторонние ассеты** (текстуры, звуки, шрифты, модели) берём только под лицензиями, разрешающими
коммерческое использование: CC0, CC-BY с атрибуцией, SIL OFL для шрифтов. CC-BY-SA и NC не используем.
Происхождение каждого стороннего ассета записываем в `assets/CREDITS.md`.

## Последствия

**Плюсы:**
- Форки любые, но атрибуция RudaTeam / F4 Studio юридически обязательна.
- Патентная лицензия защищает и пользователей, и контрибьюторов.
- Привычная лицензия: контрибьюторы и компании принимают её без юристов.

**Минусы и риски:**
- Закрытые и коммерческие форки разрешены — это осознанный выбор.
- Атрибуцию нельзя форсировать технически, только через соблюдение лицензии. Показ в титрах игры лицензия не требует, достаточно `NOTICE` в дистрибутиве.
- Часть полезных крейтов (GPL, LGPL) недоступна: ищем альтернативы или пишем своё.
