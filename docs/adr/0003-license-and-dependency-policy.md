# ADR-0003: Лицензия проекта и политика зависимостей

- **Статус:** Отложено. Лицензия проекта не выбрана, политика зависимостей ниже действует уже сейчас.
- **Дата:** 2026-09-30
- **Срок решения:** до первого публичного релиза или до первого внешнего контрибьютора — что наступит раньше
- **Связанные ADR:** 0002, 0014, 0015

## Контекст

Лицензию проекта решено выбрать позже. Варианты — от проприетарной до открытого движка с закрытой
игрой, копилефта (GPL, AGPL) или source-available (BSL, FSL). Но уже сейчас в проект попадают
зависимости, и неудачная зависимость может отрезать часть вариантов. Например, GPL-крейт закрывает
путь к проприетарной лицензии.

Пока лицензии нет, по умолчанию действует «все права защищены»: без явной лицензии никто, кроме
правообладателя, не может использовать код.

## Решение

**Лицензия проекта** не выбрана. До решения:
- файла `LICENSE` нет, все права защищены по умолчанию;
- у всех крейтов `publish = false`, поле `license` не заполняется;
- внешние контрибьюторы принимаются только по CLA — иначе потом не получится сменить лицензию.

**Зависимости** проверяет `cargo-deny` в CI. Политика консервативная: разрешительные лицензии
совместимы с любым будущим выбором, от проприетарной до AGPL.

| Категория | Лицензии |
|---|---|
| Разрешены | MIT, Apache-2.0 (в т.ч. WITH LLVM-exception), BSD-2-Clause, BSD-3-Clause, ISC, Zlib, BSL-1.0, Unicode-3.0, CC0-1.0 |
| По согласованию | MPL-2.0 (копилефт на уровне файла: если меняем такие файлы, их исходники нужно публиковать) |
| Запрещены | GPL, LGPL, AGPL, SSPL, любые некоммерческие (NC), крейты без лицензии |

Если позже выберем копилефт, ограничения можно ослабить.

**Атрибуция.** `cargo-about` генерирует список лицензий зависимостей в файл `THIRD_PARTY_LICENSES`,
и он поставляется с каждой сборкой. В игре есть экран «Лицензии».

**Ассеты** (текстуры, звуки, шрифты, модели) берём только свои или под лицензиями, разрешающими
коммерческое использование: CC0, CC-BY с атрибуцией, SIL OFL для шрифтов. CC-BY-SA и NC не используем.
Происхождение каждого стороннего ассета записываем в `assets/CREDITS.md`.

## Последствия

**Плюсы:**
- Все варианты лицензии остаются открытыми.
- Юридическая чистота зависимостей проверяется автоматически на каждый PR.

**Минусы и риски:**
- Часть полезных крейтов (GPL, LGPL) недоступна: ищем альтернативы или пишем своё.
- Лицензия SDK для моддеров зависит от этого решения (ADR-0014).
