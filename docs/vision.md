# Видение проекта

**Ruda** («руда») — воксельная песочница в духе Minecraft на Rust. Свой контент,
мультиплеер с первого дня, работа на слабом железе и глубокий моддинг.

## Цели

| Цель | Как измеряем | ADR |
|---|---|---|
| Кроссплатформенность | Windows, macOS, Linux x86_64 и ARM — уровень 1; мобильные — позже | 0004, 0005 |
| «Запускается на калькуляторе» | Raspberry Pi 4: ≥ 30 FPS, ≤ 1 ГБ ОЗУ в одиночной игре | 0005, 0008, 0009, 0016 |
| Мультиплеер | Авторитарный сервер; одиночная игра идёт на встроенном сервере | 0006, 0007 |
| Глубокий моддинг | Моды уровня Industrial Craft 2; автозагрузка модов с сервера | 0013, 0014, 0017 |
| Изюминки | LOD дальней прорисовки, реплеи и наблюдатель, геймпад и Steam Deck | 0016, 0018, 0019 |

## Принципы

1. **Истину знает только сервер.** Одиночная игра — это тот же сервер, только встроенный.
2. **Производительность — это фича.** У неё есть эталонное железо, бюджеты и автоматические бенчмарки. Регрессия — это баг.
3. **Движок без контента.** Базовая игра пишется на том же API, что и моды. Если base нужен хак, значит, API недостаточен.
4. **Базовый уровень графики обязателен, расширенный — бонус.** Геймплей никогда не зависит от возможностей GPU.
5. **Решения записываем в ADR.** Если решение дорого откатить, у него должен быть ADR.

## Что не входит в цели

- Совместимость с Minecraft: протокол, миры, ресурс-паки, моды.
- Web-версия.
- 32-битные платформы и GPU ниже уровня OpenGL ES 3.0 / OpenGL 3.3.
- Шардирование одного мира на несколько серверных процессов.
