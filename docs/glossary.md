# Глоссарий

| Термин | Значение |
|---|---|
| **Чанк** | Куб 32×32×32 блока. Единица генерации, хранения, передачи по сети и мешинга (ADR-0008). |
| **Колонка** | Вертикальный столбец чанков с общими данными: карта высот, биомы. |
| **Состояние блока** (block state) | Блок вместе со значениями его свойств, например «бревно, ось Y». Глобальный id — `BlockStateId`. |
| **Палитра** | Список разных состояний блоков в чанке. Сам массив чанка хранит индексы в палитре. |
| **Block entity** | Блок с дополнительными данными и логикой: сундук, печь, машина. |
| **Реестр** | Таблица зарегистрированного контента одного типа (блоки, предметы…) с id вида `namespace:path`. |
| **ResourceId** | Строковый идентификатор вида `namespace:path`, например `base:stone`. |
| **Тег** | Именованная группа контента, через которую моды взаимодействуют друг с другом. |
| **Тик** | Шаг симуляции сервера, 50 мс. |
| **TPS / MSPT** | Тиков в секунду (норма — 20) / миллисекунд на тик. |
| **Дальность симуляции / прорисовки** | Радиус, в котором мир тикает, и радиус, в котором он рисуется. Настраиваются отдельно. |
| **Авторитарный сервер** | Истину определяет сервер; клиент только предлагает действия. |
| **Встроенный сервер** | Сервер внутри процесса клиента, на котором идёт одиночная игра. |
| **Предсказание и согласование** | Клиент применяет свой ввод сразу, а если сервер ответил иначе, пересчитывает. |
| **Мешинг** | Превращение блоков чанка в геометрию для GPU. |
| **Greedy meshing** | Объединение соседних одинаковых граней в большие прямоугольники. |
| **AO** (ambient occlusion) | Затенение углов, в которых сходятся блоки. |
| **Cave culling** | Отсечение чанков, которые не видны через цепочку прозрачных проходов. |
| **LOD** | Упрощённое представление дальних областей (ADR-0016). |
| **Базовый / расширенный уровень рендера** | Обязательный минимум (уровень OpenGL ES 3.0) / необязательные улучшения картинки (ADR-0004). |
| **Downlevel** | Термин wgpu для устройств ниже полного уровня WebGPU. |
| **«Калькулятор»** | Эталон слабого железа: Raspberry Pi 4 или Intel HD 4000 (ADR-0005). |
| **TOFU** | Trust on first use: доверяем сертификату сервера при первом подключении и запоминаем его. |
| **Data-пак** | Мод из одних данных — блоки, рецепты, генерация — без кода. |
