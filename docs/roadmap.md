# Дорожная карта

Вехи упорядочены по зависимостям, сроков нет. Каждая веха заканчивается тем, что можно запустить и показать.

## M0 — Фундамент ✅
- [x] Workspace по ADR-0002: `rust-toolchain.toml`, `deny.toml`, профили сборки.
- [x] CI: Windows, macOS, Linux x86_64, Linux aarch64; clippy, fmt, cargo-deny, тесты.
- [x] Окно, которое очищается цветом через wgpu; бэкенд переключается флагом `--gpu-backend`.
- [x] `tracing` и Tracy.
- [x] Окно открывается и выводит кадры на всех платформах уровня 1 — проверяет смоук-тест в CI (на раннерах без GPU: Mesa, WARP).

**Готово, когда** на всех платформах уровня 1 открывается окно с цветом, а CI зелёный.

## M1 — Воксельное ядро
- Реестры и `ResourceId`; `content/base` с несколькими блоками.
- Чанки 32³ с палитрой, простая генерация по шуму.
- Мешинг (greedy и упакованные квады), массивы текстур, frustum culling.
- Абстракция ввода через действия (ADR-0019), свободная камера.
- Ломание и установка блоков — **уже через встроенный сервер и in-memory транспорт**.
- Прототипы для ADR-0008 и ADR-0009: 32³ против 16³ на Raspberry Pi.

**Готово, когда** можно летать по бесконечному миру и строить, а ADR-0008 и ADR-0009 приняты или пересмотрены.

## M2 — Мультиплеер
- QUIC (quinn), рукопожатие, синхронизация реестров, отправка чанков по приоритету.
- Физика игрока в `ruda_sim`, предсказание и согласование, интерполяция чужих игроков.
- ADR о модели движения и об аутентификации.

**Готово, когда** несколько игроков строят вместе на выделенном сервере, и при пинге 100 мс движение не «резиновое».

## M3 — Живой мир
- Сохранение (ADR-0010), освещение небом и блоками, смена дня и ночи.
- Генерация с биомами, пещерами и рельефом; грубая выборка поверхности для будущего LOD.
- Коллизии, гравитация, вода.

## M4 — «Калькулятор»
- Стенд Raspberry Pi, self-hosted runner, бенчмарк-сценарий (ADR-0005).
- Cave culling, пресеты качества, масштаб рендера, бюджеты памяти.

**Готово, когда** выполнены цели «калькулятора» из ADR-0005, а регрессии ловятся автоматически.

## M5 — Геймплей
- Предметы, инвентарь, крафт, серверные меню-контейнеры.
- Block entities, сущности и мобы; выживание: здоровье, голод, урон.
- UI-фреймворк (отдельный ADR) с навигацией фокусом.
- Параллельно — прототипы механизмов модов «IC2-lite» (ADR-0014).

## M6 — Моддинг
- Решение по ADR-0014, мод-API и SDK, перенос `base` на мод-API.
- Автозагрузка модов и ресурсов с сервера (ADR-0017).

## M7 — Изюминки
- LOD дальней прорисовки (ADR-0016).
- Полная поддержка геймпада и Steam Deck (ADR-0019).
- Реплеи и режим наблюдателя (ADR-0018).
